## 架构分层要点

| 层 | 内容 |
| --- | --- |
| **1 应用工程**（考古场景应用） | **基础能力层**：模型路由、知识库检索、工具调用、记忆管理；**认知编排层**：规划与反思、多智能体协同、工作流编排、RAG 引擎；**业务智能体层**：九类考古研究场景智能体；**应用可观测**：全链路追踪、成本监控、编排可观测、业务效果评估与监控 |
| **2 模型工程**（领域适配） | 三层解耦的模型体系 —— **基座模型**（大语言模型 / 多模态模型）、**领域模型**（考古大语言模型 / 考古多模态模型）、**场景模型**（器物分型分式、墓址分期推断、文化溯源判别、聚落等级划分、墓主身份考证等）；配套 **效果优化**（RL 训练 / SFT 训练 / 持续训练 / 提示词优化）、**模型压缩**（量化 / 蒸馏 / 剪枝）、**推理加速**（缓存优化 / 系统调度 / 并行策略 / 计算加速）、**模型可观测**（训练监控 / 版本可观测 / 推理监控） |
| **3 数据工程**（三类数据资产） | **数据湖**：考古报告、拓片、**三维点云**、**遥感**、学术论文、通识教材，经内容结构化汇聚；**数据加工**：文本 / 图片 / 音视频 / 其它模态数据加工；**训练数据**（预训练、SFT、RL）、**应用数据**（知识图谱、本体库、向量知识库、图文检索库）、**评测数据**（多模态感知、知识理解、时空推理、学术生成）；**数据可观测**：血缘追踪、质量监控、漂移监控 |
| **4 资源工程**（算力 · 存储 · 网络） | **网络系统**：RoCE、TCP；**国产算力**：GPU、NPU、DPU；**存储系统**：文件、对象、块存储；调度能力：算力切分、算力池化、异构调度、拓扑亲和、资源隔离、资源监控 |
| **5 安全工程**（应用 · 模型 · 数据、资源） | **应用安全**：内容安全围栏、学术伦理与版权、运行时安全、审计与溯源；**模型安全**：模型引入评估、模型幻觉治理、模型防御、版本管理与追溯；**数据安全**：分级分类管理、脱敏与隐私保护、防篡改与溯源、数据安全审计；**资源安全**：算力安全、存储安全、网络安全、平台运行安全 |

## 相关技术进展与后续演进

架构评审（见 `架构评审意见_20260915.md`）指出的主要演进方向：

- **互操作协议层**：将「工具调用」展开为 MCP（工具 / 数据连接）+ A2A（智能体协作）+ Harness（统一执行控制面）+ AGENTS.md 约定；
- **评估工程**：在可观测之外独立设立评测集治理、离线 / 在线评测、回归门禁与幻觉专项；
- **上下文工程**：将「记忆管理」展开为上下文组装、分层记忆、压缩摘要、缓存与 Token 预算治理；
- **数据标准化**：术语 / 元数据 / 格式 / 质量控制四位一体，并以 CIDOC CRM / ARK-O 作为本体基准；
- **考古专属模型链路**：三维点云分类、生成式三维重建、空间考古 GIS / 遥感、微遗物智能分选。
